# Defeat the Monster!

Fight with monsters, Upgrade your weapon. Defeat the Final Boss!

## Requirements
- [.NET SDK 10.0](https://dotnet.microsoft.com/download)
- OS: Windows / macOS / Linux
## How to Run

```bash
git clone https://github.com/Sm1t0921/20230597_CS20200_Term_project
cd 20230597_CS20200_Term_project
dotnet run
```

## How to Play

You can choose between two actions: 
1. Fight
2. Upgrade
In Fight the menu, you can fight with monsters. If you successfully defeat the monster, you earn Gold.
In Upgrade menu, you can upgrade your weapon with Gold.
The Goal is to defeat Lv 5 Monster.
